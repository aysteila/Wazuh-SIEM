# Wazuh SIEM - Intrusion Detection

## Project Overview
Deployment of a Wazuh SIEM laboratory for security monitoring,
intrusion detection, and custom rule development.

## Objectives
- Deploy Wazuh Manager and Agents.
- Detect SSH brute-force attempts.
- Analyze network scans.
- Monitor file integrity (FIM).
- Develop custom detection rules.

## Technologies
- Ubuntu 24.04
- Wazuh
- Kali Linux
- Nmap
- Hydra
- Git and GitHub

## Project Status
In progress.
